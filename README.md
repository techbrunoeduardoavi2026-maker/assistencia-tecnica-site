# 💻 Assistência Técnica em Informática

Site institucional desenvolvido para a empresa **Assistência Técnica em Informática**, fundada em 2024 em Blumenau/SC.  
O objetivo é apresentar os serviços oferecidos, informações sobre a empresa e facilitar o contato direto com os clientes via WhatsApp.

---

## 🖼️ Identidade Visual
- **Logo**: Representa tecnologia e suporte técnico com design minimalista.  
- **Capa**: Imagem tecnológica moderna usada na página inicial para destacar a marca.  

---

## 📄 Estrutura do Projeto
- `index.html` → Página inicial com apresentação da empresa, logo, capa e chat WhatsApp.  
- `sobre.html` → História, missão, visão e valores da empresa.  
- `servicos.html` → Lista dos principais serviços oferecidos.  
- `contato.html` → Formulário de contato e mapa de localização.  
- `style.css` → Arquivo de estilos centralizado para todas as páginas.  

---

## 🚀 Funcionalidades
- Apresentação institucional com capa e logo.  
- Contato via WhatsApp direto pelo botão ou chat integrado.  
- Formulário de contato para envio de mensagens.  
- Mapa do Google mostrando a localização da empresa.  
- Design responsivo e moderno, pronto para publicação.  

---

## 🛠️ Tecnologias Utilizadas
- **HTML5** → Estrutura das páginas.  
- **CSS3** → Estilização e layout responsivo.  
- **JavaScript** → Integração com WhatsApp e interatividade.

📖 Manual de Publicação no GitHub Pages
1. Criar o Repositório
Acesse GitHub e faça login.

Crie um novo repositório com o nome:
assistencia-tecnica-site

Defina como público e não adicione README inicial (pois já vamos criar).

2. Adicionar os Arquivos do Site
No seu computador, organize os arquivos do projeto:

index.html
sobre.html
servicos.html
contato.html
style.css
Imagens (logo, capa, etc.)
Faça o upload dos arquivos para o repositório no GitHub.

3. Publicar no GitHub Pages
No repositório, vá em Settings → Pages.

Em Branch, selecione main e a pasta /root.

Clique em Save.

O GitHub Pages irá gerar automaticamente o link:

Código
https://seuusuario.github.io/assistencia-tecnica-site
4. Testar o Site
Acesse o link gerado e verifique se todas as páginas estão funcionando.
Caso precise atualizar, basta fazer commit dos novos arquivos no repositório.
